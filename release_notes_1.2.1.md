## BetterRoads v1.2.1 - Security Update

This is a minor release that introduces critical security updates to the administrator dashboard login flow.

**What's New in this Build:**
- **End-to-End Encryption:** The administrator login flow now utilizes a robust AES-256-GCM tunnel, ensuring your username and password are fully encrypted in the application layer before they ever hit the network payload. 
- General stability improvements and bug fixes.
