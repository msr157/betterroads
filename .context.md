# BetterRoads Context

## Current Status
- MERN Stack App for IoT/Sensor data collection (pothole/road quality detection).
- **Infrastructure Context:** Deployed via Dokploy to a 3-node Docker Swarm (`mayank-mainframe-server`, `BetterRoad-VM`, `rackops-vm`).
- **Routing:** Cloudflare Tunnel (`cloudflared-main`, tunnel name: `betteroads`) → Traefik → Swarm Service.
- **Registry:** Pushed to local registry (`127.0.0.1:5000`) before Swarm deployment.

## Architectural Decisions
- Source repository was migrated from local Gitea to GitHub (`msr157/betterroads`).
- `https` and `certificateType` are disabled in Dokploy; TLS is handled strictly by Cloudflare Edge.
- Vite build commands run successfully on the manager node during Dokploy build pipeline.
